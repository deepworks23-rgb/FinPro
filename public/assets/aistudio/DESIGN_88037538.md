## Brand & Style

This design system expresses clarity, control, and progressive financial confidence. Rooted in the visual standards of modern global fintechs, it bridges high-utility banking functions with the approachable clarity of a lifestyle app.

### Design Principles
- **Clarity Over Clutter:** High-density financial figures must be legible instantly. Visual hierarchies strip out gratuitous noise in favor of intentional spacing and clear groupings.
- **Empathetic Feedback:** Financial interactions trigger emotional states. Green denotes health, yield, and income; coral indicates outflow, warnings, and limits; indigo drives action and progress.
- **Tactile Modernism:** Surfaces feel grounded and tangible without skeuomorphic excess, using subtle borders, layered white cards, and calculated inner shadows to suggest tactile affordances.
- **Data Precision:** Numerical amounts, exchange rates, and transaction streams prioritize geometric alignment and tabular metrics to guarantee effortless scanning.

## Colors

The palette leverages a pristine light background, allowing high-contrast typography and semantic color tokens to dictate transaction states.

### Core Roles
- **Canvas (`#F8FAFC`):** The foundational cool slate canvas underpinning all viewports.
- **Surface (`#FFFFFF`):** High-level card backgrounds, elevated sheets, and persistent containers.
- **Primary / Action (`#4F46E5` & `#6366F1`):** Indigo guides primary user flows, authentication, transfer submissions, and key active states.
- **Positive / Income (`#10B981`):** Emerald green for cash inflows, investments in profit, budget surplus, and verification badges.
- **Negative / Outflow (`#EF4444`):** Coral red strictly reserved for expenses, debt, warning flags, and destructive operations.
- **Neutral Foreground (`#0F172A` & `#64748B`):** Deep slate provides high legibility for lead monetary values and headlines, while medium slate serves secondary labels, metadata, and timestamps.

## Typography

Typography establishes an instant sense of order between balance displays, navigational items, and itemized transaction feeds.

- **Headlines (`Plus Jakarta Sans`):** Soft, contemporary geometric grotesque used for primary screen anchors, account module headings, and balance summaries.
- **Body & Data (`Inter`):** Workhorse sans with strict vertical metrics. All financial figures must use tabular figures (`font-variant-numeric: tabular-nums;`) to keep decimal points and integers aligned vertically across transaction rows.

## Layout & Spacing

The layout is built upon an 8pt dynamic fluid grid with a strict vertical rhythm. 

### Breakpoints & Adaptive Behavior
- **Mobile (< 768px):** Single-column layout with `1rem` outer canvas margin. Transaction feeds and balance cards occupy full width minus margins. Bottom navigation bar anchors high-frequency routes (Transfers, Feed, Analytics, Cards).
- **Tablet (768px - 1024px):** 8-column layout with `1.5rem` gutters. Top overview module splits into primary balance and quick actions side by side.
- **Desktop (> 1024px):** 12-column layout capped at a maximum width of `1280px`. Left rail contains persistent navigation, middle columns host balance sheets and category analytics, and the right 4 columns contain incoming bills and pending transfers.

## Elevation & Depth

Visual depth is achieved through layered white surfaces on the `#F8FAFC` canvas, reinforced by subtle low-contrast boundaries rather than heavy drop shadows.

- **Level 0 (Canvas):** Pure `#F8FAFC`. Zero elevation, base background for the overall viewport.
- **Level 1 (Default Card):** `#FFFFFF` surface accompanied by a hairline border: `1px solid rgba(15, 23, 42, 0.06)` and an ambient shadow: `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.03), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Interactive & Hovered Cards):** Used for actionable items, cards under pointer focus, and active widgets: `box-shadow: 0 10px 15px -3px rgba(15, 23, 42, 0.05), 0 4px 6px -4px rgba(15, 23, 42, 0.02)`.
- **Level 3 (Modals & Action Sheets):** `#FFFFFF` layer with `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.03)`, framed with a 1px border `rgba(15, 23, 42, 0.08)`.

## Shapes

The design uses generous, organic roundedness inspired by modern physical credit cards and high-end consumer technology.

- **Containers & Primary Modules (`rounded-2xl` / 1rem to 1.5rem):** Applied to total balance cards, quick-send modules, and modal containers.
- **Interactive Controls (`rounded-xl` / 0.75rem):** Form inputs, action buttons, filter triggers, and list row selection states.
- **Micro-Elements (`rounded-full` / Pill):** Category tags, transaction count indicators, account status pills, and toggle thumb elements.

## Components

### Buttons
- **Primary:** Background `#4F46E5` with `#FFFFFF` text. Height 48px, radius `rounded-xl`, font weight 600. Active state uses `#4338CA` with a subtle scale transform (`scale(0.98)`).
- **Secondary:** Surface `#FFFFFF`, border `1px solid rgba(15, 23, 42, 0.12)`, text `#0F172A`. On hover, surface shifts to `#F8FAFC`.
- **Destructive:** Background `#EF4444` with `#FFFFFF` text.

### Cards
- Base surface of `#FFFFFF`, corner radius `1.25rem` (`rounded-2xl`), padding `1.5rem`, wrapped in a crisp `1px solid rgba(15, 23, 42, 0.05)`.
- Internal dividers within cards use `1px solid #F1F5F9`.

### Category Badges & Chips
- Compact dimensions (height: 28px, horizontal padding: 10px, radius: full pill).
- Semantic light-tint styling:
  - **Income/Health:** Background `#ECFDF5`, text `#065F46`.
  - **Expense/Alert:** Background `#FEF2F2`, text `#991B1B`.
  - **Neutral/Category:** Background `#F1F5F9`, text `#334155`.
  - **Indigo Focus:** Background `#EEF2FF`, text `#3730A3`.

### Transaction Lists
- High-density rows with 64px min-height. Left side includes a 44px circular icon container with category-tinted backgrounds.
- Center displays bold merchant/payee title above muted category/timestamp.
- Right displays tabular amount: green with a `+` prefix for deposits, deep slate or coral with a `-` prefix for expenses.

### Budget & Progress Bars
- Track height: 8px, track background `#E2E8F0`, track radius `rounded-full`.
- **States:**
  - **Normal / Healthy (< 75%):** Fill color `#10B981`.
  - **Warning (75% - 90%):** Fill color `#F59E0B`.
  - **Critical / Exceeded (> 90%):** Fill color `#EF4444`.

### Input Fields
- Height 48px, background `#FFFFFF`, border `1px solid #CBD5E1`, text `#0F172A`, placeholder `#94A3B8`, radius `rounded-xl`.
- Focus ring: `2px solid #6366F1` with an offset of `2px`. Numeric input variants should automatically format as currency with fixed prefix units.
